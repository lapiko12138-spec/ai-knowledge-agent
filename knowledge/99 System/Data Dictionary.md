# AI Knowledge Data Dictionary

## Classification

- `A`：新知识
- `B`：已知知识的新解释
- `C`：已有知识的延伸
- `D`：新闻 / 事件
- `E`：观点 / 判断
- `F`：案例
- `G`：暂时没有长期价值

## Level

- `L1`：入门概念
- `L2`：技术原理
- `L3`：工程实现
- `L4`：Research Frontier

## Relationship Types

- `child_of`：下位概念
- `depends_on`：依赖或前置知识
- `enables`：带来能力
- `improves`：优化对象
- `contrasts_with`：方法对比
- `used_in`：应用于
- `related_to`：一般相关

## Priority

`Priority = Relevance × Novelty × Connection × Impact`

四项分别取 0–5。乘积用于排序，不代表事实可信度。
